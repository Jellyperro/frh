JavaScript 定时器

setTimeout 延迟执行 · setInterval 周期重复 · clearTimeout / clearInterval 清除

01

setTimeout

单次延迟执行
const Fu_t = setTimeout(() => { console.log("3 秒后执行一次"); }, 3000); // clearTimeout(Fu_t); // 取消
3
点击按钮启动，延迟 3 秒执行一次

setTimeout(fn, ms) 等待 ms 毫秒后调用一次 fn，返回一个 timerId；期间调用 clearTimeout(id) 可以取消。

02

setInterval

周期重复执行
const Fu_t = setInterval(() => { console.log("每秒执行一次"); }, 1000); // clearInterval(Fu_t); // 停止
00:00
点击按钮启动，每秒更新一次

setInterval(fn, ms) 每隔 ms 毫秒反复调用 fn，直到手动 clearInterval(id)；长时间运行的定时器务必清除，否则内存泄漏。

控制台日志（日志面板）

两种定时器对比

名称setTimeoutsetInterval
作用延迟一段时间后执行 一次每隔一段时间 反复 执行
签名setTimeout(fn, delay, ...args)setInterval(fn, delay, ...args)
清除clearTimeout(id)clearInterval(id)
返回值都返回一个 number 类型的 timerId，传给对应的 clear 函数即可取消
执行时机到点立即执行一次到达间隔就执行；注意它不等待上一次回调执行完就会排下一次
常见坑忘记清除导致后台一直跑（虽然只执行一次）忘记清除 = 内存泄漏；用它做倒计时/轮询时务必在卸载时 clear
替代写法想要"等上次执行完再等下一次"，用 setTimeout 递归调用自己
