Web 前端长度单位

CSS 中的长度单位分为绝对单位和相对单位，下图展示各单位的实际效果

绝对单位（固定尺寸）

px（像素）

width: 100px

最常用的单位，1px 对应屏幕上的一个物理像素点（CSS 逻辑像素）。

pt（点）

width: 72pt

印刷单位，1pt = 1/72 英寸。屏幕显示中较少使用。

cm / mm / in

width: 2.54cm / 25.4mm / 1in

物理长度单位。1in = 2.54cm = 25.4mm = 72pt = 96px。主要用于打印样式。

相对单位（相对于其他值）

em

width: 10em

相对于自身 font-size 的长度。此处 font-size=16px，所以 10em = 160px。

rem

width: 6rem

相对于根元素（html）的 font-size。默认 1rem = 16px，不受嵌套影响。

%（百分比）

width: 60%; height: 50%

相对于父元素对应属性的值。此处父容器宽度约 282px，高度 80px。

vw（视口宽度）

width: 20vw

1vw = 视口宽度的 1%。窗口越宽，元素越大。

vh（视口高度）

height: 15vh

1vh = 视口高度的 1%。窗口越高，元素越高。

vmin / vmax

25vmin / 12vmax

vmin = vw 与 vh 中较小者的 1%；vmax = 较大者的 1%。

ch

width: 20ch

相对于当前字体中 "0" 字符的宽度。常用于限制文本行宽（如 60-75ch）。

calc() 计算

width: calc(100% - 40px)

混合不同单位进行计算，如百分比与像素相减，实现弹性布局。

fr（Grid 分数）

grid-template-columns: 1fr 2fr

Grid 布局专用。1fr 表示占据 1 份可用空间，2fr 占 2 份。

使用场景建议

px — 边框、阴影、固定尺寸元素。
rem — 字体大小、间距，便于全局缩放和无障碍适配。
em — 相对于当前组件的间距（如按钮 padding），随组件字体缩放。
% — 响应式布局中的弹性宽度。
vw / vh — 全屏背景、大标题等与视口联动的元素。
ch — 控制文本阅读宽度，提升可读性。
fr — CSS Grid 中的比例分配。
