JavaScript 程序结构

条件结构 if / switch · 循环结构 for / while / do...while

01

条件结构 · if...else 成绩等级

if (Fu_score >= 90) { Fu_grade = "优秀"; } else if (Fu_score >= 80) { Fu_grade = "良好"; } else if (Fu_score >= 60) { Fu_grade = "及格"; } else { Fu_grade = "不及格"; }

按分数段输出等级，展示 if...else if...else 多分支判断。

02

条件结构 · switch 星期判断

switch (Fu_day) { case 6: Fu_name = "周六"; break; case 7: Fu_name = "周日"; break; default: Fu_name = "工作日"; }

switch 匹配固定取值，default 处理其余情况。

03

循环结构 · for 九九乘法表

for (let Fu_i = 1; Fu_i <= 9; Fu_i++) { for (let Fu_j = 1; Fu_j <= Fu_i; Fu_j++) { // Fu_i × Fu_j = 积 } }

双重 for 循环嵌套，外层控制行、内层控制列。

04

循环结构 · while 与 do...while

while (Fu_i <= 100) { Fu_sum += Fu_i; // 1+2+...+100 Fu_i++; } do { Fu_n++; // 至少执行一次 } while (Fu_n < 5);

while 先判断后执行；do...while 先执行后判断，至少执行一次。
