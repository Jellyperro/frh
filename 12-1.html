CSS 变量（自定义属性）

使用 --变量名 定义、var() 调用，实现统一配色、作用域隔离与动态主题切换

基础用法

全局变量 :root

--Fu_main: #039;
由 --Fu_main 控制

在 :root 中声明，全文档任意元素都能通过 var(--Fu_main) 使用。

var() 回退值

var(--Fu_not-defined, #9c27b0)
使用回退颜色

当变量未定义时，var() 的第二个参数作为回退值生效，避免样式失效。

局部作用域

.Fu_local { --Fu_main: #009688; }
组件内重新定义

变量遵循 CSS 层叠规则，在组件内重新声明即可覆盖全局值，只影响该子树。

进阶用法

calc() 与变量运算

width: calc(100% - 60px)
渐变条

变量可与 calc() 结合，参与尺寸计算，实现弹性自适应布局。

统一间距

gap: var(--Fu_gap)

把间距抽成变量，整站改动一处即可，减少重复的魔法数字。

响应式变量

@media { :root { --Fu_resp: 50% } }
宽度随视口变化

在媒体查询中修改变量值，即可让多个元素随屏幕尺寸同步变化（窄屏为 50%）。

变量驱动动画

width: var(--Fu_size)

关键帧中也可引用变量，动画过程中的尺寸与颜色都取自自定义属性。

主题切换

body.Fu_dark { --Fu_bg: #1a1a1a; }
点击上方按钮试试

给 body 添加类名即可整体替换一组变量，无需修改各元素样式。
