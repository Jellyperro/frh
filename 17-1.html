JSON 数据格式

JavaScript Object Notation · 语法规则 · 序列化与解析

JSON 语法规则

  1. 数据以键值对形式书写，键必须用双引号包裹，例如 "name": "傅若涵"。
  2. 值的类型只允许：字符串、数字、布尔值、null、对象、数组。
  3. 成员之间用逗号分隔，但最后一个成员后不能多余加逗号。
  4. 不支持注释、单引号、undefined 和函数，这些都会导致解析失败。
  5. 最外层可以是对象 { }，也可以是数组 [ ]。
01

JSON 的六种值类型

类型 JSON 写法 说明
字符串 String "傅若涵" 必须使用双引号，不能用单引号
数字 Number 929 / 3.14 整数、小数、科学计数法均可
布尔 Boolean true / false 全小写，不能写成 True
空值 Null null 表示空值，全小写
对象 Object {"name": "傅若涵"} 无序键值对集合，用花括号
数组 Array ["HTML", "CSS"] 有序值列表，用方括号
02

序列化：JS 对象 → JSON 字符串

const Fu_student = { name: "傅若涵", id: 929, major: "计算机24009", skills: ["HTML", "CSS", "JavaScript"], graduated: false, remark: null }; JSON.stringify(Fu_student); // 紧凑 JSON.stringify(Fu_student, null, 2); // 缩进 2 空格

JSON.stringify() 把 JS 对象转换成符合 JSON 语法的字符串，便于传输和存储。

03

解析：JSON 字符串 → JS 对象

const Fu_text = '{"name":"傅若涵","id":929,"skills":["HTML","CSS","JavaScript"]}'; const Fu_obj = JSON.parse(Fu_text); Fu_obj.name; // "傅若涵" Fu_obj.skills[1]; // "CSS"

JSON.parse() 把 JSON 字符串还原成 JS 对象，之后就能用点语法或方括号访问属性。

04

嵌套结构：对象与数组组合

{ "class": "计算机24009", "students": [ { "name": "傅若涵", "id": 929, "score": 95 }, { "name": "李明", "id": 930, "score": 88 } ] }

JSON 支持对象与数组任意嵌套，可以表达树形、列表等复杂结构。

05

合法与非法：JSON 与 JS 对象的区别

写法 结果 原因
{"name": "傅若涵"} 合法 键使用双引号，符合 JSON 语法
{name: "傅若涵"} 非法 键没有加双引号（JS 对象允许，JSON 不允许）
{'name': '傅若涵'} 非法 使用了单引号
{"a": 1,} 非法 最后一个成员后多了逗号
{"a": undefined} 非法 JSON 不支持 undefined
{"a": 1 /* 注释 */} 非法 JSON 不支持注释

解析失败时 JSON.parse() 会抛出异常，实际开发中需用 try...catch 捕获。
