JavaScript 六种基础数据类型

Number · String · Boolean · Undefined · Null · Object

01

Number 数值型

let Fu_num = 929; let Fu_pi = 3.14;

整数与浮点数都属于 Number，不区分整型和浮点型。

02

String 字符串型

let Fu_str = "傅若涵";

用单引号、双引号或反引号包裹的文本序列。

03

Boolean 布尔型

let Fu_isPass = true;

只有两个取值：true 或 false，常用于条件判断。

04

Undefined 未定义型

let Fu_und;

声明了变量但未赋值时，其值默认为 undefined。

05

Null 空型

let Fu_null = null;

表示"空值"，typeof 返回 object 是历史遗留问题。

06

Object 对象型

let Fu_obj = { name: "傅若涵", id: 929 };

键值对的集合，数组、函数也属于 Object 类型。
