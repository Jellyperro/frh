图① · 智能客服系统处理流程图

用户请求 → 意图识别 → 检索增强 RAG → 大模型生成 → 安全护栏 → 回复；异常分支：低置信度转人工 / 安全拦截 / 反馈闭环。

flowchart TD
    subgraph 接入层
        A[用户发起请求
Web / APP / 企微] --> B{会话鉴权}
        B -- Token 无效 --> C[拒绝并返回 401]
        B -- Token 有效 --> D[对话管理]
    end

    subgraph 对话理解
        D --> E[意图识别 Intent]
        D --> F[实体抽取 NER]
        D --> G[槽位填充]
        E --> H{置信度 ≥ 阈值?}
        H -- 是 --> I[进入 RAG 流程]
        H -- 否 --> Z[转人工客服]
    end

    subgraph RAG 检索增强
        I --> J[查询改写 Rewrite]
        J --> K[多路召回
Vector + BM25]
        K --> L[重排序 Rerank]
        L --> M{检索到文档?}
        M -- 是 --> N[拼装 Prompt
上下文 + 系统提示]
        M -- 否 --> O[纯 LLM 生成
无检索增强]
    end

    subgraph 大模型 & 安全
        N --> P[LLM 生成回复]
        O --> P
        P --> Q{安全护栏检查}
        Q -- 违规 --> R[返回安全拦截提示]
        Q -- 合规 --> S[回复用户]
    end

    subgraph 反馈闭环
        S --> T{用户反馈?}
        T -- 👍 满意 --> U[结束会话]
        T -- 👎 不满意 --> V[记录 Bad Case]
        V --> W[人工标注 → 知识库 / 模型微调]
        W --> K
    end

    subgraph 后台运维
        X[日志 & Trace] -.-> D
        X -.-> E
        X -.-> P
    end

图② · 智能客服系统 ER 实体关系图

核心实体：用户、会话、消息、知识库文档、FAQ、反馈、人工坐席，及它们之间的外键关联（1:N / N:M）。

erDiagram
    USER {
        bigint id PK "用户ID"
        varchar username "用户名"
        varchar phone "手机号"
        varchar email "邮箱"
        tinyint status "状态 0禁用 1启用"
        datetime created_at "创建时间"
    }

    SESSION {
        bigint id PK "会话ID"
        bigint user_id FK "→ USER.id"
        varchar channel "渠道 web/app/wx"
        varchar intent "当前意图"
        tinyint status "0进行中 1已结束 2转人工"
        datetime started_at "开始时间"
        datetime ended_at "结束时间"
    }

    MESSAGE {
        bigint id PK "消息ID"
        bigint session_id FK "→ SESSION.id"
        tinyint role "1用户 2机器人 3人工"
        text content "消息内容"
        float intent_conf "意图置信度"
        bigint faq_hit FK "→ FAQ.id"
        bigint doc_hit FK "→ DOC.id"
        datetime created_at "发送时间"
    }

    DOC {
        bigint id PK "文档ID"
        varchar title "文档标题"
        varchar category "分类"
        text content "正文"
        varchar url "来源链接"
        float quality_score "质量分"
        int version "版本号"
        datetime updated_at "更新时间"
    }

    FAQ {
        bigint id PK "FAQ ID"
        text question "问题"
        text answer "标准答案"
        varchar tag "标签"
        int hit_count "命中次数"
        float acc_rate "准确率"
        tinyint status "0下架 1上架"
    }

    FEEDBACK {
        bigint id PK "反馈ID"
        bigint message_id FK "→ MESSAGE.id"
        bigint user_id FK "→ USER.id"
        tinyint rating "评分 1~5"
        text comment "用户评论"
        tinyint handled "0未处理 1已处理"
        datetime created_at "反馈时间"
    }

    AGENT {
        bigint id PK "坐席ID"
        varchar name "姓名"
        varchar dept "部门"
        tinyint status "0离线 1忙碌 2空闲"
        int serving_count "服务中会话数"
        datetime online_at "上线时间"
    }

    HUMAN_TICKET {
        bigint id PK "工单ID"
        bigint session_id FK "→ SESSION.id"
        bigint agent_id FK "→ AGENT.id"
        tinyint priority "1低 2中 3高"
        tinyint status "0待分配 1处理中 2已解决 3关闭"
        text description "问题描述"
        text solution "解决方案"
        datetime assigned_at "分配时间"
        datetime resolved_at "解决时间"
    }

    KNOWLEDGE_DOC {
        bigint id PK "关联ID"
        bigint knowledge_base_id FK "→ DOC.id"
        bigint session_id FK "→ SESSION.id"
    }

    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    MESSAGE }o--|| FAQ : "命中"
    MESSAGE }o--|| DOC : "引用"
    MESSAGE ||--o| FEEDBACK : "收到"
    USER ||--o{ FEEDBACK : "提交"
    SESSION ||--o| HUMAN_TICKET : "转人工"
    AGENT ||--o{ HUMAN_TICKET : "处理"
    SESSION }o--o{ DOC : "检索"
